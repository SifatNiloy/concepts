# PostgreSQL Learning Guide - From Zero to SQL Master

Welcome to the PostgreSQL Guide! PostgreSQL is the world's most advanced open-source relational database and the #1 choice for Next.js, Node.js, and modern cloud applications.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: Relational Database mental model, Tables, Rows, Types & Docker setup with `psql`.
- **Level 2 - Basics**: CRUD Operations (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `WHERE`, `ORDER BY`, `LIMIT`).
- **Level 3 - Intermediate**: Relationships & JOINs (`1-to-Many`, `Many-to-Many`, `INNER JOIN`, `LEFT JOIN`, Foreign Keys).
- **Level 4 - Real World**: Aggregations (`GROUP BY`, `HAVING`), Indexes (speeding up queries 100x), and `EXPLAIN ANALYZE`.
- **Level 5 - Advanced**: Transactions (ACID), JSONB (Using Postgres as a NoSQL Document Store), and Views.
- **Level 6 - Pro**: Connecting Next.js with Prisma / Drizzle ORM, Docker Compose Integration, Migrations & Automated Backups.
