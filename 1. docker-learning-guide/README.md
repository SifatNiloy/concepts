# Docker Learning Guide - From Zero to Hero

Welcome! This guide will teach you Docker step by step. You already know Next.js, so you're not a complete beginner to programming - you just need to learn Docker.

## What You'll Learn

1. **Level 1 - Beginner**: What is Docker? Why do people use it?
2. **Level 2 - Basics**: Running your first containers
3. **Level 3 - Intermediate**: Building your own images with Dockerfiles
4. **Level 4 - Real World**: Dockerizing your Next.js app
5. **Level 5 - Advanced**: Docker Compose, networking, volumes
6. **Level 6 - Pro**: Deployment, best practices, real-world scenarios

## How to Use This Guide

- Each level has a markdown file with explanations and commands
- Type every command yourself - don't copy paste!
- If a command doesn't work, read the error message carefully
- Take breaks between levels

## Prerequisites

- You know how to use a terminal/command prompt
- You know basic Next.js (you do!)
- You have Docker installed (we'll check this in Level 1)

## Let's Start!

cd /home/sifat/codes/docker/docker-learning-guide
