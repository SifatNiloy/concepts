# Networking & Reverse Proxy Guide (Nginx, Caddy & Free SSL)

Welcome to the Networking & Reverse Proxy Guide! You already have your apps running inside Docker. Now you need users to be able to visit **`https://yourdomain.com`** instead of typing an ugly IP and port like `http://143.24.11.90:3000`.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: What is a Reverse Proxy? The Hotel Concierge analogy.
- **Level 2 - Basics**: Domain Names, DNS Records (A, CNAME), and Port 80 vs 443.
- **Level 3 - Intermediate**: Running **Nginx** inside Docker to route multiple apps.
- **Level 4 - Real World**: **Caddy** — The Modern Reverse Proxy with 100% Automatic Free SSL Certificates (Let's Encrypt).
- **Level 5 - Advanced**: Docker Internal Networks & Service Discovery (Zero open ports).
- **Level 6 - Pro**: Cloudflare Integration, DDoS protection, Rate Limiting & WebSockets.
