# Redis Learning Guide - From Zero to In-Memory Speed Master

Welcome to the Redis Guide! Redis (**Re**mote **Di**ctionary **S**erver) is the world's most popular in-memory data store, used by virtually every high-traffic web application on Earth (Twitter, GitHub, Netflix, Stack Overflow).

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: What is Redis? The Desk vs Filing Cabinet analogy & running Redis in Docker.
- **Level 2 - Basics**: Core Data Structures (Strings, Hashes, Lists, Sets, Sorted Sets) & TTL (Expiration).
- **Level 3 - Intermediate**: The Cache-Aside Pattern in Next.js / Node.js (Cutting DB load by 90%).
- **Level 4 - Real World**: API Rate Limiting (Preventing DDoS & scrapers) & Real-time Pub/Sub Messaging.
- **Level 5 - Advanced**: Background Job Queues with **BullMQ** (Asynchronous email sending & task processing).
- **Level 6 - Pro**: Persistence (`RDB` vs `AOF`), Eviction Policies, and Monitoring Redis with Docker Compose.
