# Infrastructure as Code (IaC) Guide with Terraform & OpenTofu

Welcome to the final missing link of modern DevOps!

You know how to write a `Dockerfile` to create containers, and `docker-compose.yml` to run multiple containers.  
Now imagine: **What if you could create real cloud servers, databases, DNS records, and firewalls using simple code files instead of clicking around in cloud web consoles?**

That is **Infrastructure as Code (IaC)**, and **Terraform / OpenTofu** is the global industry standard.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: What is IaC? The Architect's Blueprint analogy (ClickOps vs Code).
- **Level 2 - Basics**: Providers, Resources, Variables, and the 4 Sacred Commands (`init`, `plan`, `apply`, `destroy`).
- **Level 3 - Intermediate**: Managing State (`terraform.tfstate`) & Drift Detection.
- **Level 4 - Real World**: Provisioning Cloud Resources for Free (LocalStack / Free Cloud Providers).
- **Level 5 - Advanced**: Reusable Modules & Multi-Environment setups (Dev vs Prod).
- **Level 6 - Pro**: GitOps integration — Terraform automated inside GitHub Actions pipelines.
