# CI/CD Learning Guide - From Zero to Hero with GitHub Actions

Welcome to the CI/CD Guide! You already know how to build Docker images by typing `docker build` on your laptop. Now, let's automate everything so that **GitHub does the hard work whenever you push code**!

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: What is CI/CD? The factory conveyor belt analogy & your first YAML workflow.
- **Level 2 - Basics**: GitHub Actions fundamentals (Workflows, Events, Jobs, Steps, Runners).
- **Level 3 - Intermediate**: Automated testing & linting before anything gets built.
- **Level 4 - Real World**: Building and pushing your Next.js Docker image to Docker Hub & GHCR automatically.
- **Level 5 - Advanced**: Secrets management, environment variables, matrix builds & branch protection.
- **Level 6 - Pro**: Continuous Deployment (CD) — Auto-deploying your Docker container to a live server on `git push`.
