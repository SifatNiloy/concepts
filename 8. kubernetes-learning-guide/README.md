# Kubernetes (K8s) Learning Guide (From Zero to Cluster Operator)

Welcome to Kubernetes! You've learned Docker, CI/CD, Linux servers, Reverse Proxies, and Monitoring.  
Now you are finally ready to learn **Kubernetes** without getting overwhelmed.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: What is Kubernetes? The Cargo Ship analogy (Docker Compose vs K8s).
- **Level 2 - Basics**: Core Objects — Pods, Nodes, and your first local cluster using **K3d / Minikube** (100% Free).
- **Level 3 - Intermediate**: Deployments & ReplicaSets — Self-healing containers & zero-downtime rolling updates.
- **Level 4 - Real World**: Services & Ingress — Routing external web traffic into your Pods.
- **Level 5 - Advanced**: ConfigMaps, Secrets & Persistent Volume Claims (Databases in K8s).
- **Level 6 - Pro**: Helm Charts — The package manager for Kubernetes (Deploying full stacks in 1 command).
