# Monitoring & Logging Guide (Prometheus, Grafana & Loki)

Welcome to the Monitoring & Logging Guide! Once your containers and services are running 24/7, you need eyes inside the machine.

Instead of waking up to angry emails from users saying *"Your app is broken!"*, you want **real-time dashboards and automated alerts** when memory is high or response times slow down.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: The Three Pillars of Observability (Metrics, Logs, Traces).
- **Level 2 - Basics**: Quick Container Monitoring with **Portainer** (Web UI for Docker) & `docker stats`.
- **Level 3 - Intermediate**: Collecting Server & Container Metrics with **Prometheus** and **Node Exporter**.
- **Level 4 - Real World**: Building Stunning Visual Dashboards with **Grafana** (100% Free & Open Source).
- **Level 5 - Advanced**: Centralized Log Aggregation with **Grafana Loki** & **Promtail** (Farewell `docker logs`).
- **Level 6 - Pro**: Automated Alerting to Discord / Telegram / Slack when errors spike.
