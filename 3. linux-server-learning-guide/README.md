# Linux & Server Fundamentals (From Zero to Server Admin)

Welcome to the Linux & Server Guide! Containers and CI/CD runners all run on **Linux**. Understanding how Linux works transforms you from an app developer into a full-stack engineer who can operate any cloud server with confidence.

---

## 🎯 What You'll Learn

- **Level 1 - Beginner**: The Linux mental model, the terminal filesystem hierarchy, and essential navigation commands.
- **Level 2 - Basics**: File permissions (`chmod`, `chown`), managing users & sudo security.
- **Level 3 - Intermediate**: Processes, system services (`systemd`), and reading logs (`journalctl`).
- **Level 4 - Real World**: SSH keys, remote access, firewalls (`ufw`), and hardening your server.
- **Level 5 - Advanced**: Getting a **100% Free Forever Cloud Server** (Oracle Cloud Always Free Tier / AWS EC2 Free Tier) and installing Docker on it.
- **Level 6 - Pro**: Automated backups, cron jobs, and production server maintenance.
